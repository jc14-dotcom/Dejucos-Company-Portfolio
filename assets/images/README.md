# Image Requirements

This folder should contain the following images for the portfolio website:

## Required Images

### About Section
- `team-photo.jpg` (800x600px) - Team photo for the About section

### Portfolio Projects
- `project-1.jpg` (600x400px) - E-commerce Platform screenshot
- `project-2.jpg` (600x400px) - Mobile Banking App screenshot  
- `project-3.jpg` (600x400px) - Corporate Website screenshot
- `project-4.jpg` (600x400px) - SaaS Dashboard screenshot
- `project-5.jpg` (600x400px) - Learning Platform screenshot
- `project-6.jpg` (600x400px) - Healthcare App screenshot

## Image Guidelines

- **Format**: JPG or PNG
- **Quality**: High resolution, optimized for web
- **Size**: Keep file sizes under 500KB for better performance
- **Dimensions**: Follow the recommended dimensions above
- **Content**: Professional, high-quality images that represent your work

## Placeholder Images

You can use placeholder images from:
- https://unsplash.com/ (free stock photos)
- https://via.placeholder.com/ (placeholder image service)
- https://picsum.photos/ (Lorem Picsum service)

## Adding Images

1. Place your images in this folder
2. Update the image paths in `index.html` if you use different filenames
3. Make sure to use the `loading="lazy"` attribute for better performance
